# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

The active colorscheme is **Sakura Nocturne**. `colors/sakura-nocturne.lua` defines the palette and plugin highlights. `lua/plugins/colorscheme.lua` selects it in LazyVim, while `lua/plugins/sakura-ui.lua` and `lua/lualine/themes/sakura-nocturne.lua` apply it to Lualine. Copy this directory to `~/.config/nvim/` to use the complete configuration.
